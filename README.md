# 말씀의 결

요한복음의 반복, 대조, 상징과 구약 배경을 따라가고 본문 관찰 뒤 개혁주의 해설을 펼쳐 보는 정적 웹앱입니다.

## 실행

```bash
npm install
npm run dev
```

## 검증

```bash
npm run check
```

## GitHub Pages 배포

`main` 브랜치에 푸시하면 GitHub Actions가 테스트와 빌드를 실행한 뒤 `dist`를 GitHub Pages에 배포합니다.

처음 한 번은 저장소의 **Settings → Pages → Build and deployment → Source**에서 **GitHub Actions**를 선택해야 합니다. 배포 주소는 다음과 같습니다.

<https://dong-ha.github.io/BIBE/>

현대 한국어 성경 번역 전문은 포함하지 않습니다. 앱은 장절과 직접 작성한 요약을 제공하며, 성경 본문은 대한성서공회 웹사이트에서 읽도록 연결합니다.
