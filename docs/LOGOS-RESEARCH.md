# Logos 설치 자료 조사

조사일: 2026-10-12. 설치 서재의 SQLite 카탈로그를 읽기 전용으로 확인했다. 카탈로그에는 152개 레코드가 있고 ResourceManager에는 148개 설치 리소스가 있다. 세부 서지와 짧은 자체 요약은 `raw/logos-catalog.json`에 기록한다. 로컬 경로, 계정 정보, 책 본문은 기록하지 않는다.

## Tim Keller 공개 자료 확인

두란노 한국어판 네 권은 Logos 한국어 카탈로그의 서지 및 책 소개를 확인했다. 사사기와 로마서 1의 영어 원서 출판사 공개 샘플은 각각 18쪽과 15쪽 PDF로 확인했다. 사사기는 목차·서문·1장 초반, 로마서 1은 목차·서문·로마서 개관·1장 일부를 읽었다. Romans 8–16 For You 17쪽 샘플은 인쇄본 7–9쪽 서론과 11–17쪽 로마서 8:1–13 해설을 읽었다. Galatians For You 20쪽 샘플은 인쇄본 9–11쪽 서론과 13–23쪽 갈라디아서 1:1–9 해설을 읽었다. 두 PDF의 직접 링크와 자체 요약은 각 참고 문서에 기록했다.

네 권 참고 문서는 저자 저술 전문 확인 기록이 아니다. 영어 원서의 공개 샘플에서 직접 읽은 범위, 로컬 Logos 한국어판 일부의 직접 열람 범위, 공개 목차, 출판사 소개와 서지 메타데이터를 각기 구분해 기록했다. 영어 미리보기 열람은 한국어판이나 책 전체를 읽은 것으로 볼 수 없다. 추가 해석과 적용은 성경 본문에 직접 근거해야 한다.

## 설치 후보

- `LLS:CSKTMPTYOTSG`, `LLS:CSKTMPTYNTSG`: CASKET EMPTY 구약·신약 개관. Logos/출판사 소개에서 구속사 전체 흐름을 목표로 한다고 확인했다.
- `LLS:NWCTYCTCHDEVO`: 뉴시티 교리문답 해설. 52문답과 기본 교리 소개를 확인했다. TGC의 공개 문답 페이지로 개별 질문을 추가 확인할 수 있다.

세 자료의 본문을 읽은 것은 아니다. `wiki/references/logos-casket-ot.md`, `logos-casket-nt.md`, `logos-new-city.md`는 서지와 소개 범위만 기록한다.

출처별 접근 범위와 주제 요약은 [사사기](../wiki/references/logos-keller-judges.md), [로마서 1](../wiki/references/logos-keller-romans-1.md), [로마서 2](../wiki/references/logos-keller-romans-2.md), [갈라디아서](../wiki/references/logos-keller-galatians.md) 자료를 참조한다.

## 설치된 책의 실제 열람

Logos 51.1.0.3에서 설치된 한국어판 갈라디아서를 일반 프로그램 화면으로 열었다. 갈라디아서 3:1–14를 다루는 5장 중 「뿌리 뽑아야 할 습성」 단락을 직접 읽고 짧은 자체 요약을 참고 문서에 추가했다. 인증 정보나 암호화된 리소스의 우회 추출은 사용하지 않았다. 화면 본문을 열람할 수 있다는 사실은 확인했지만, 모든 책의 전문을 자동으로 읽을 수 있다는 뜻은 아니다. UI 자동화의 접근성 트리는 해당 본문 텍스트를 노출하지 않았다.

SQLite는 처음에는 원본을 읽기 전용으로 조회했다. 프로그램 실행 후 잠금과 WAL 관련 오류가 발생한 조회에는 로컬 임시 사본을 사용했다. 공개 카탈로그는 선별한 서지와 자체 요약만 포함한다.
