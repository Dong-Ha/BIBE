# 출처 조사와 편집 기준

조사 확인일: 2026-10-12. 이 보고서는 출처 접근 상태와 질문별 근거 범위를 기록한다. 저자 원문, 사이트의 자료 설명, 이 프로젝트의 성경 해석을 같은 수준의 근거로 취급하지 않는다. 전문은 공개 위키나 Git에 넣지 않는다. 확인한 12개 저자 자료의 공개 HTML 응답은 해시를 붙여 `raw/snapshots/`에 로컬 보관하며, 이 디렉터리는 `.gitignore` 대상이다. 추적되는 `raw/source-catalog.json`에는 출처 메타데이터와 짧은 요약만 둔다. 공개 위키에는 간략한 [조사와 인용 방법](/references/research-method.md)을 제공한다.

## 저자 자료 조사

### 이정규 목사

공식 시광교회 사이트에서 이정규 본인이 작성자로 표시된 글 여섯 편 이상을 확인했다. 기존 블로그의 `시광교리문답 소개`, `그리스도인과 심리학`, `설교자의 정서 1`, `설교자의 정서 2` 네 편과 공식 목회서신의 `시광교회의 공예배 철학`, `결혼식 방법에 대한 새로운 제안` 두 편은 공개 페이지의 HTML을 직접 가져와 전체 글이 담긴 페이지 설명 메타데이터를 읽었다. 공개 페이지의 응답 바이트는 해시가 붙은 로컬 스냅샷으로만 보관하며 원문 전문을 Git이나 공개 산출물에 싣지 않는다. 웹 열람 도구는 해당 게시물에 403을 반환했지만, 일반 HTTP 요청으로 인증 없이 공개 페이지를 읽을 수 있었다. 접근 상태와 링크는 각 참고 문서 및 `raw/source-catalog.json`에 기록했다.

추가 확인 경로를 넓히려고 시광교회 설교 자료 PDF, CTK·복음과도시 글도 찾아보았다. 설교 PDF는 검색 색인에서 일부 본문을 확인했지만 PDF 전문을 직접 가져오지 못해 세부 저자 주장의 근거로 사용하지 않는다. 복음과도시의 2025년 Keller 관련 글도 검색 색인 일부만 노출되고 직접 열람이 막혔다. 반면 2019년 뉴스앤조이의 `목사는 정치인인가`는 이정규 본인 기고문으로 기사 본문 전문을 확인할 수 있었고, 복음이 공적 발언과 행동의 방향을 형성해야 한다는 저자의 논지를 확인했다. 이번 공개 페이지에서 전문 확인 가능한 이정규 저자 글은 최소 일곱 편이다. 다만 이것은 제한된 검색 범위이며, 영상 설교의 제목만으로 내용을 확인했다고 보지 않는다.

### Tim Keller

Gospel in Life의 공식 설교 페이지 여덟 건 이상에서 설교 정보와 공개 개요를 읽었다. 설교 개요 열람은 저자 직접 글 전문 정독과 별도 집계한다. 여기에는 누가복음 15장, 하박국, 십자가와 자유, 믿음, 부활, 용서, 다원주의 사회 설교가 포함된다. 대부분 설교 전체를 청취하거나 전사와 대조한 것은 아니다. `Peace – Overcoming Anxiety`는 자료 목록을 확인했을 뿐 상세 설교 설명을 보지 못해 논거로 사용하지 않는다.

직접 저술 전문을 읽은 Keller 글은 “The Gospel in All Its Forms”, “Social Media, Identity, and the Church”, “Reconstructing Faith: Christianity in a New World”, “Wisdom from the Letters of John Newton”, “Lemonade on the Porch (Part 1)”, “God, Freedom, and Love” 여섯 편이다. 앞 네 편과 추가 두 편은 Gospel in Life Quarterly의 본문을 끝까지 확인했고, “The Gospel in All Its Forms”는 Christianity Today에서 전체 본문을 읽었다. 따라서 목표한 여섯 편의 직접 글 전문 확인을 달성했다. 참고 문서에는 논지 요약과 적용 범위만 남겼다. 여섯 페이지의 공개 HTML 응답은 해시와 함께 로컬 무시 대상 스냅샷으로 보관하고 원문 전문은 Git이나 웹앱에 싣지 않는다. Keller의 직접 기고문 “The Gospel in All Its Forms”는 Christianity Today에서 본문 전체를 열어 읽었다. Spring 2008 Leadership Journal 글은 복음의 통일성과 성경·청중에 따른 표현의 다양성, 개인 구원과 창조 회복의 폭을 함께 다룬다. 상세한 출처·요약은 [저자 자료](/references/keller-gospel-all-forms.md)에서 본다. 해당 글 전문을 위키나 원자료 카탈로그에 복사하지 않았다.

## 편집에 반영한 차이와 한계

- 이정규 자료는 질문형 교리교육, 심리학을 대하는 균형, 설교 정서, 복음 중심 예배, 복음과 문화적 실천에 대한 여섯 편 이상의 직접 글을 확인한 범위에서만 활용했다. 이를 목사의 모든 설교를 대표하는 공식 방법론으로 묘사하지 않는다.
- 이정규의 직접 글은 복음을 예배와 공동체의 습관, 공적 삶에 연결한다. 이를 그의 모든 설교를 대표하는 단일 방법론으로 확대하지 않는다. Keller의 직접 기고문은 하나의 복음을 여러 형태로 전하면서 전체 내용을 결국 연결해야 한다고 말한다. 이 내용을 적용할 때 복음의 내용을 청중에 맞춰 생략·변경할 수 있다는 뜻으로 축소하지 않았다.
- Keller 직접 글의 전문 확인 목표는 여섯 편으로 충족했다. 여기에는 복음의 여러 형태, 정체성과 온라인 소통, 신앙 재구성, 은혜와 변화, 후기기독교 사회의 환대 공간, 문화 참여와 사랑에 관한 글이 들어간다. 질문 문서별 주장 커버리지 표에서는 실제로 연결된 자료의 접근 상태를 별도로 표시한다.
- Keller 설교는 다수가 공식 설교 개요에 기반한다. 전문을 대조했다고 말하지 않으며, 출처 문서가 공개한 설명보다 더 세밀한 설교 주장을 만들어 넣지 않는다.
- 성경의 직접 문맥, 그리스도를 통한 해석, 약속·성취와 주제적 관계를 혼동하지 않도록 구분했다. 질문 문서의 본문 요약은 원문 출처보다 성경 본문 자체에 근거한다.
- 고통, 학대, 교회 상처에는 성급한 원인 설명이나 화해 압박을 피하고, 사실 확인·안전·책임·애도·현실 지원을 먼저 말한다.


## 기도 자료 확장

확인일: 2026-10-12T16:22:21.805188Z. TGC 공식 뉴시티 교리문답 38–40의 공개 영어 문답·성경 인용·해설·묵상·기도문을 직접 읽었다. 각 묵상 저자는 John Piper, Thabiti Anyabwile, Alistair Begg이며 Keller의 개별 묵상으로 표시하지 않았다. Logos 한국어판은 기존 서지·소개 확인 범위를 유지한다. 공개 참고자료 3편에 실제 읽은 범위를 기록했고, 질문·본문·세 모임 과정에서 저자 요약과 사이트가 작성한 해석·적용을 구별했다.

기도 시작하기는 마태복음 6:5–15, 기다림은 마태복음 26:36–46과 시편 13 및 요한일서 5:14–15, 말이 막히는 순간은 로마서 8:26–27과 시편 62:1–12를 근거로 삼았다. 성경 문맥은 대한성서공회 공개 본문과 대조했다. 응답을 얻을 자격을 기도 능력에서 찾는 흐름 대신, 그리스도를 통해 하나님께 나아가는 은혜와 성령의 도우심에 초점을 맞췄다. 개별 고통의 원인·기도 응답 결과·침묵의 영적 상태는 자료로 단정하지 않았다. 현 개정본의 검토 주체는 Codex이며 사람 검토로 표시하지 않는다.
